# Генератор датасета HOLD Cloud для YOLO



Скрипт берёт исходные PDF-документы или изображения без искусственно добавленных пометок, рендерит их в изображения и случайным образом добавляет облачка разного размера и положения. 
Рядом с облачком или внутри него может быть добавлена надпись `HOLD`. Для каждого изображения автоматически создаётся файл разметки в формате YOLO.

## Возможности

- генерация заданного количества изображений;
- добавление от 0 до N облачков на одно изображение;
- разные размеры и положения облачков;
- разные варианты расположения надписи `HOLD`;
- возможность создавать облачка без надписи;
- фиксированный размер шрифта `HOLD`;
- автоматическое создание YOLO-разметки;
- создание preview-изображений для проверки bbox.

## Установка зависимостей


pip install pillow pymupdf
Пример запуска
python generate_hold_cloud_dataset_v2.py ^
  --input-dir "input-dir\base_pages" ^
  --output-dir "input-dir\hold_dataset" ^
  --samples 50 ^
  --min-clouds 1 ^
  --max-clouds 5 ^
  --hold-font-size 26 ^
  --preview
Структура результата

После запуска будет создана папка с датасетом:

hold_dataset/
  images/
    train/
    val/
  labels/
    train/
    val/
  previews/
  data.yaml
  metadata.jsonl

Папка images содержит изображения для обучения и проверки.
Папка labels содержит файлы разметки в формате YOLO.
Папка previews содержит изображения с нарисованными bounding box для ручной проверки.
Файл data.yaml можно использовать при обучении YOLO.

Формат разметки

Каждая строка .txt-файла соответствует одному облачку:

class_id x_center y_center width height

Координаты нормализованы относительно размеров изображения.

В текущей версии класс один:

0 - hold_cloud
